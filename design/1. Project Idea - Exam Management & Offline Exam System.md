# EXAM PAPER MANAGEMENT & OFFLINE EXAM ORGANIZATION SYSTEM — VU TIEN HIGH SCHOOL

## I. SYSTEM STRUCTURE

### 1. Storage & Question Bank System (for teachers / teacher groups)

- The question bank is organized by topics derived from the lessons in the textbook.
  - Lesson 1:
    - Topic 1
    - Topic 2...
  - Lesson 2:
    - Topic 3
    - Topic 4...

- Each topic contains the following question formats:
  - Multiple choice
  - True/False
  - Short answer

- Each format is further divided into 4 cognitive levels:
  - Knowledge (Recognition)
  - Comprehension (Understanding)
  - Application
  - Advanced Application

- Teachers / teacher groups upload questions to the system following the structure above. The system can provide templates so teachers build questions to a standard format, avoiding question-recognition errors.

- Teachers create a matrix for each test/exam as required: either fixed matrices (for periodic tests such as Mid-Term 1, End of Term 1, Mid-Term 2, etc.) or matrices for individual assessments (topic/chapter quizzes).

### 2. Test / Exam Creation System

- Generate candidate numbers based on the class / grade / subject / exam session lists.
- Generate exam papers according to the matrix — 2 methods:
  - Generate a number of papers and random paper codes equal to the exact number of candidates (no master paper): used when the number of questions in the question bank is large.
  - Generate papers from a fixed number of master papers, then shuffle them into multiple paper codes: used when the number of questions in the question bank is still limited.
- Organize students to take the test/exam:
  - Students receive their candidate number and a computer (in a centralized exam room).
  - Students enter their full name and candidate number to log into the system.
  - The system cross-checks the name and candidate number to confirm the candidate.
  - The teacher opens the system (releases the exam) on the server.
  - The teacher monitors and supports through the system.
- The system grades, exports score lists, and produces statistics.

## II. BUILD PLAN FOR THE OFFLINE EXAM SYSTEM (IN PYTHON)

### 📅 Phase 1: Designing the System "Backbone" (Estimated: 1–2 weeks)

The goal is to create the data structure that stores the diagram exactly: Lesson → Topic → Format → Level.

- **Task 1: Design the Database (SQLite)**
  - Create a `Chapters_Lessons` table (manages lessons, e.g. Lesson 1, Lesson 2...).
  - Create a `Topics` table (manages topics belonging to a lesson, e.g. Topic 1, Topic 2...).
  - Create a `Questions` table storing: question content, format (1: Multiple choice, 2: True/False, 3: Short answer), level (Knowledge → Advanced Application), answer, explanation.
  - Create an `Exams` table (stores exam session information) and an `Exam_Matrix` table (stores the matrix structure requested by the teacher).
- **Task 2: Initialize the Python Project (FastAPI/Flask)**
  - Set up a standard folder structure (Backend, Frontend Templates, Static files).
  - Write the database connection code using SQLAlchemy or sqlite3.

### 📅 Phase 2: Question Bank Management Module (Estimated: 1–2 weeks)

Helps teachers get data into the system as conveniently as possible.

- **Task 3: Build manual question entry**
  - Create a web form for teachers to select Lesson → Topic → Format (the interface changes dynamically: choosing True/False shows 4 statements A, B, C, D to tick True or False; choosing Short answer shows a single input box for the answer).
- **Task 4: Enhancement — Bulk import from Excel/Word files (important feature)**
  - Teachers cannot enter thousands of questions by hand. Use the `pandas` library (for Excel) or `python-docx` (for Word).
  - Define a template file. Teachers only need to fill in the correct columns: _Lesson Name | Topic Name | Format | Level | Question | Answer_. Python scans the file and loads it into the database in bulk within 3 seconds.

### 📅 Phase 3: Automatic Exam Generation Algorithm by Matrix (Estimated: 1–2 weeks)

This is the "brain" of the system — selecting random questions while strictly following the matrix.

- **Task 5: Build the exam matrix creation interface**
  - Let teachers enter requirements. Example: _Lesson 1 - Topic 1 - Multiple choice - Knowledge: take 2 questions._
  - Teachers enter the number of "master papers" to generate (e.g. generate 4 master papers).
- **Task 6: Write the filtering and shuffling algorithm (Python backend)**
  - Use SQL `SELECT` statements combined with Python's `random.sample()` to draw questions from the database that satisfy each exact row of the matrix.
  - **Generate paper codes for candidates:** From the teacher's 4 master papers, when a student enters the exam, the system automatically shuffles the question order and shuffles the answer options (for multiple-choice questions) to create a distinct paper code for each machine, ensuring no two students receive the same paper.

### 📅 Phase 4: LAN Exam Organization Module (Estimated: 1–2 weeks)

- **Task 7: Student exam-taking interface (Frontend — HTML/CSS/JS)**
  - Design a countdown timer in JavaScript (auto-locks and submits when time runs out).
  - Display questions in the exact format of the Ministry of Education and Training: True/False format clearly shows the 4 statements a, b, c, d to select; Short answer format shows a text/number input box.
  - Integrate auto-save every 5 seconds in case of a power outage.
- **Task 8: Teacher proctor screen**
  - A dashboard interface for real-time monitoring: which machine is working, how many questions have been answered, which machine has lost connection.
  - Buttons for "Start timer" and "Collect all papers".

### 📅 Phase 5: Grading, Statistics & Packaging (Estimated: 1–2 weeks)

- **Task 9: Write automatic grading logic**
  - _Format 1 (Multiple choice):_ correct = full marks, incorrect = 0.
  - _Format 2 (True/False):_ implement the grading formula per the Ministry's new regulations (1 correct statement = 0.1 points, 2 = 0.25 points, 3 = 0.5 points, all 4 = 1.0 points — or configurable).
  - _Format 3 (Short answer):_ match the string/number entered by the student against the standard answer.
- **Task 10: Statistics & Data export**
  - Build a consolidated score sheet for the entire exam room.
  - Export score data to Excel (`pandas.to_excel()`).
  - Plot a score distribution chart and a "bottleneck" chart (questions where more than 70% of students answered incorrectly) using `matplotlib`.
- **Task 11: Package for offline operation (PyInstaller)**
  - Package the entire Python codebase into a single `.exe` file so it can be carried to the school's computer lab server and run immediately without installing a development environment.
